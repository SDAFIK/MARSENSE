# UI system

The interface uses dark forest backgrounds, warm neutral context, mint verified knowledge and amber pending/conflicting evidence. Color always accompanies text, icons or a route pattern. Orbital priors and former routes remain visible; confirmed footprints and Route Beta use mint, while Alpha uses a dashed warm line. The map is central to the mission.

Six views: landing, Mission Control, Astronaut View, Evidence Inspector, Exploration Memory and Before & After. Mission Control combines the map, assumptions, route costs, observation/review and timeline. Astronaut View removes the region/assumption ledger and timeline to focus on the active traverse, relevant review and immediate next action. NO_ROUTE or a challenged traverse tells the astronaut to pause and review. Inspector separates raw image, expected/observed classes, original model quality, footprint source and reviewer. Memory presents retained events and inherited evidence. Comparison keeps the original Alpha map beside current knowledge.

Responsive breakpoints collapse the sidebar to compact navigation and the map/action layout to one column. Inputs have visible labels, keyboard focus, semantic buttons, a skip link and live status/error announcements. Map zoom and fit buttons work by keyboard. Motion respects reduced-motion preference. Offline imagery uses same-origin cached assets; WebGL failure falls back to a labeled local SVG map.

Loading and connection failures are explicit. No map change occurs before the server commits review. Weak permanent terrain evidence requires human identification, expired records are marked stale, rejected evidence remains inspectable and dynamic observations never become permanent terrain. Only relevant discrepancies interrupt the astronaut; off-route minor differences are recorded silently.

The responsive screenshot set in `docs/screenshots` is generated by Playwright and inspected visually. Keyboard/overflow/image-load checks supplement it. This is not a formal assistive-technology or WCAG conformance certification.
